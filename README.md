# 机场登机口 3D 仿真（B12 机位）

基于 Three.js 的登机桥（乘客登机桥 PBB）自动对接 3D 场景。飞机停稳后，系统根据所选舱门的
世界坐标实时解算登机廊桥的水平旋转角、伸缩长度、立柱升降高度、通道俯仰与接机舱偏转角，
完成自动对接；切换机型、舱门或调整停机位置时自动重新解算。若对接路径会碰撞机身/发动机/
机翼，或超出机械运动包线，立即停止操作并给出明确状态。

## 运行

```bash
npm install
npm run dev        # 启动开发服务器
npm run build      # 生产构建
```

## 场景内容

- 停机坪与机位标线：机位居中线、停止线、翼尖净距线、廊桥活动包线、禁停斜线区、机位编号
- 航站楼：玻璃幕墙、发光窗户、B12 登机口标识、固定廊道与支撑柱
- 客机（程序化建模，4 种机型）：A320、737-800、777-300ER、A380-800（含双层舱门/四发布局）
  机身、后掠翼、翼下发动机、垂尾/平尾、起落架、舷窗、驾驶舱、可对接舱门
- 登机廊桥：固定廊道 → 柔性波纹罩 → 升降转盘（rotunda）→ 伸缩主通道 → 可偏转接机舱+软围裙
- 地勤车辆：行李牵引车（3 节拖车）、加油车、摆渡车、登机车、传送带车、安全锥桶
- 安全区域：机身安全带（红）、舱门作业区（黄）、发动机进气危险圈（红），均随机型/位姿更新

## 操作

- 机型 / 对接舱门下拉切换（换机型走“廊桥撤回 → 新机滑入 → 重新解算”流程）
- 纵向 / 横向停靠偏差、机身偏航角滑块（连续拖动防抖重算）
- 自动对接、撤回廊桥、重新引导入位、复位
- 全景 / 廊桥 / 舱门 / 俯视四个预设视角，鼠标可自由环绕
- “参数变更后自动重新解算”开关，关闭后改为手动触发对接

## 机械模型与限位（src/config.js）

| 自由度 | 范围 |
| --- | --- |
| 水平旋转 yaw | -165° ~ 165°（机械止档） |
| 主通道伸缩 | 7.0 ~ 19.0 m |
| 转盘升降高度 | 3.0 ~ 6.5 m |
| 通道俯仰 | -10° ~ 10° |
| 接机舱偏航补偿 | ±25° |

## 解算与安全逻辑（src/sim/kinematics.js）

1. 由舱门世界坐标求水平 yaw，校验止档；
2. 由水平距离校验伸缩上下限（过近/过远）；
3. 由舱门外法线与进近方向求接机舱偏航，校验补偿范围；
4. 枚举转盘高度，求满足伸缩/俯仰包线且俯仰最小的可行姿态；
5. 沿通道+接机舱轴线以 0.5m 步长采样，对机身（胶囊）、发动机（胶囊）、
   机翼（外翼三角形面片）做净距检测，安全距离分别为 0.6 / 0.8 / 0.25m；
   选中舱门贴合机身属设计预期，沿机身切线方向做邻域豁免，斜向擦碰仍会被检出；
6. 任一校验失败即中止：面板红警、警示灯闪烁、碰撞点红球高亮，并绘制红色尝试路径。

状态机（src/sim/simulator.js）：
无飞机 → 入位中 → 已停稳 →（解算中 → 桥体运动）→ 已对接；
任意阶段可撤回；换机型走独立的“撤桥 → 换型 → 入位”序列。
