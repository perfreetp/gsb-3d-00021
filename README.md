# 机场登机口 3D 场景

从零实现的 G21 登机口三维调度仿真：飞机滑入停机位后，系统依据前舱门位置重新计算廊桥旋转、伸缩和高度，按“旋转 → 高度调节 → 伸缩贴合”的顺序对接；路径碰撞或机械超限时立即停止并展示原因。

## 运行

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/index.html`。Three.js 通过 CDN import map 加载，无需安装依赖。

## 场景内容

- 停机坪：廊位线、G21 标识、红白安全边界、交通锥和动态安全包络。
- 客机：机身、机头、机翼、尾翼、发动机、舷窗、起落架和前舱门，可切换 A320、B737-800、E175、B777-300ER。
- 登机廊桥：固定基座、旋转轴、伸缩通道、高度调节、末端调节舱和软密封罩。
- 地勤车辆：GPU、泡沫消防车和摆渡车沿安全道路循环移动。
- 航站楼：主楼、玻璃幕墙、连接走廊和圆形旋转基座。

## 操作

- 切换飞机型号或拖动 X/Z 停靠位置：廊桥先收回，飞机重新滑入，停稳后自动重算并对接。
- 取消“飞机停稳后自动重新计算并对接”后，可用“重新对接”手动执行。
- “收回廊桥”将廊桥恢复到安全初始姿态；“急停”立即取消所有运动。
- 绿色包络表示当前解算安全，红色包络表示碰撞或机械限位失败。

## 运动学约束

- 水平旋转：±125°。
- 水平伸缩：9–36 m。
- 末端高度：2.8–5.2 m。
- 最大通道坡度：10°。
- 主通道与机身胶囊轮廓最小净距：1.05 m；末端密封罩允许按舱门法向贴合。
- 碰撞检测使用三维线段到机身胶囊轮廓的距离，覆盖圆柱段、机头/机尾半球段和高度差。

## 测试

```bash
node --test
```

测试覆盖正常对接、机型切换后重算、机身碰撞、枢轴侧穿越、伸缩越界、坡度/旋转限位。

也可以用 URL 参数复现碰撞工况：

```text
index.html?x=12&z=0
```
